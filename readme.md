## Домашнее задание. Знакомство с Django в рамках обучения по специальности "Разработчик Python" университета Skypro.  

**Задачи выполняемые программой:**  
Отработка темы "Формы, валидация." в Django.

**Для пользователей:** 
Запуск сервера: `python manage.py runserver`, в браузере открыть страницу http://127.0.0.1:8000

**Для разработчиков:**  
Установка:  
 - скачать дистрибутив с python.org и установить Python;  
 - скачать и установить PostgreSQL, создать пользователя с правами владельца базы данных.
Предупреждение:  
❌ Не давайте пользователю SUPERUSER (это администратор всей СУБД);  
❌ Не используйте пользователя postgres (суперпользователь по умолчанию) для Django;  
❌ Не храните пароль в коде (используйте .env).

**Требуемые версии и зависимости:**  
 - в соответствии requirments.txt. 
  
**Состав программы:**  
- manage.py - точка входа;  
- site_22/ - директория проекта;   
- catalog/ - директория приложения catalog; 
- blog/ - директория приложения blog;  
- requirments.txt - файл списка зависимостей и версий;  
- make_fixtures.py - создание-выгрузка фикстур автоматически;
- recreate_data.py - повоторное заполнение БД.  


## Особенности
- Проект содержит два приложения: catalog - веб магазин и blog - блог;  
- Два режима просмотра блога: **Посетитель** (только опубликованные посты) 
  и **Admin** (все посты + кнопки управления).
- Режим переключается кнопкой в интерфейсе главной страницы, состояние хранится в сессии.
- При достижении 100 просмотров поста автор получает email-уведомление (в консоль при `DEBUG=True`);  
- При значении `DEBUG=False` в случае ошибочного адреса страницы обоих приложений отрабатывается кастомная общая страница 404;


## Формы и валидация (ДЗ параграфа 26.1)  

- **Catalog** (`ProductForm`, `ContactForm`):  
  - Автоматическая стилизация полей через `BootstrapFormMixin`;  
  - постоянные и настройки приложения catalog вынесены в constant.py:  
	- запрещённые к вводу слова в списке FORBIDDEN_WORDS;  
	- максимальный допустимый размер загружаемого файла изображения в карточку товара в байтах - MAX_IMAGE_SIZE_BYTES;  
	- разрешённые форматы загружаемого файла изображения в списке TYPE_OF_IMAGE;  
	- настройки атрибутов (`class`, `type`, `accept`) в словаре `FIELD_ATTRIBUTES`;  
	- Кастомные placeholder (с учётом склонений) в словаре `REPLACEMENT_PLACEHOLDERS`.  
В текущих моделях булевых полей нет, но при их добавлении стилизация чекбокса будет применена автоматически через FIELD_ATTRIBUTES.  

  - Валидация:  
    - `clean_price` — цена не может быть отрицательной;  
    - `clean_name`, `clean_description` — запрещённые слова;  
    - `clean_image` — формат (JPEG, PNG) и размер (до 5 МБ).  
- **Blog** — без изменений (работает на CBV; режимы - "Пользователь", "Admin"; 100 просмотров - отправка сообщения на почту).
